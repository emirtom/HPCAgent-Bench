# Code reuse map

Where one piece of functionality was implemented more than once, and where the shared helper now
lives. "Before" locations are `file:line` at commit `020bfca44` (paths relative to `hpcagent_bench/`
unless they start with `agent/` or `tests/`). **Consolidated** rows were merged in the reuse pass that
added this page. **Proposal** rows are not merged yet; the helper column names the proposed home.
**Kept** rows were checked and left alone on purpose; the row says why.
